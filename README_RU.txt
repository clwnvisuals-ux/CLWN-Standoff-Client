CLWN STANDOFF CLIENT — VERSION 0.10
===================================

Статус пакета: Android Studio project / source release candidate.
Это исходный проект, НЕ собранный APK. В этой среде не настроены Android SDK и Gradle, поэтому APK не был собран или протестирован на устройстве.

Что есть в v0.10:
- нативная Android-оболочка на Kotlin с WebView;
- автономный интерфейс, встроенный в APK как локальный asset;
- редактор предпросмотра прицела и HUD-макета;
- локальные профили с импортом/экспортом JSON;
- локальный журнал заметок;
- работа без сетевого разрешения и без root;
- версия приложения 0.10 (versionCode 10).

Что НЕ входит:
- overlay поверх Standoff 2;
- чтение памяти/файлов процесса игры;
- инъекции, читы, anti-aim или обход античита;
- автоматическое измерение FPS/Ping игры. Поля FPS/PING в HUD — демонстрационные подписи.

Сборка на ПК:
1. Установить Android Studio и Android SDK Platform 35.
2. Установить JDK 17 (обычно поставляется с Android Studio).
3. Открыть папку CLWN_Standoff_Client_v0.10 как проект в Android Studio.
4. Дождаться Gradle Sync.
5. Выбрать Build > Build APK(s).
6. Debug APK обычно появится в app/build/outputs/apk/debug/app-debug.apk.

Для релиза:
- собрать release APK через Build > Generate Signed Bundle / APK;
- создать собственный keystore и хранить его в безопасном месте;
- протестировать импорт/экспорт JSON, сохранение профилей и поведение на целевом Android-устройстве.

Приватность:
- приложение не запрашивает разрешение INTERNET;
- настройки и журнал хранятся в локальном WebView storage;
- удаление данных приложения удалит локальные настройки и записи.

Это независимый компаньон, не связанный с разработчиками Standoff 2.
