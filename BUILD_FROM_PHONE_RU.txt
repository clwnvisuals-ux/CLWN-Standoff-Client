CLWN STANDOFF CLIENT v0.10 — ОБЛАЧНАЯ СБОРКА APK С ТЕЛЕФОНА

Важно: сам APK ещё не собран. Этот набор настраивает автоматическую сборку на GitHub Actions, чтобы ПК не требовался.

ЧТО НУЖНО
- аккаунт GitHub;
- браузер на телефоне;
- файлы из этого набора.

ШАГИ
1. Скачай CLWN_Standoff_Client_v0.10_CloudBuildKit.zip и распакуй его на телефоне.
2. Открой https://github.com/new и создай репозиторий. Например, имя: clwn-standoff-client. Можно выбрать Private.
3. Открой созданный репозиторий в браузере.
4. Нажми Add file → Upload files. Загрузи в корень репозитория файл CLWN_Standoff_Client_v0.10_Source.zip из распакованного набора. Сделай Commit changes.
5. Теперь добавь workflow: Add file → Create new file.
6. В поле имени файла введи точно: .github/workflows/build.yml
7. Вставь содержимое файла build.yml из распакованного набора. Сохрани через Commit changes.
8. Открой вкладку Actions в репозитории. Выбери “Build CLWN Standoff Client APK”. Если сборка не стартовала автоматически, нажми Run workflow.
9. Дождись зелёной отметки успешного запуска. Открой запуск workflow и найди раздел Artifacts.
10. Скачай CLWN-Standoff-Client-v0.10-debug-APK.zip, распакуй его и открой app-debug.apk.
11. Android может попросить разрешить установку приложения из браузера/файлового менеджера. Разрешай только если уверен, что скачал артефакт из своего репозитория и успешного запуска GitHub Actions.

ЕСЛИ СБОРКА УПАЛА
- Открой красный запуск в Actions, затем шаг с ошибкой.
- Скопируй последние 30–50 строк ошибки и пришли их сюда — помогу исправить.

ПРИМЕЧАНИЯ
- Это debug APK, а не подписанный production-релиз.
- Для обновления версии/подписанного релиза потребуется отдельная настройка ключа подписи.
- Приложение — офлайн-компаньон. Оно не внедряется в Standoff 2, не читает память игры и не меняет механику матча.
